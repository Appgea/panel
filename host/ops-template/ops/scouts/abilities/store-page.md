Lens: the store page as a stranger reads it in five seconds: the name, two lines, three pictures. Read only.

1. The run names the app. Read its store page: name, subtitle, first lines, first three screenshots.
2. Read the page's numbers: impressions, page views, installs.
3. Read `apps/<key>.md` for the app's one-line point. That line is what the page must say.
4. Hold the page against these checks: the point is in the name or subtitle, the first screenshot shows the main use, the text speaks the user's words.

A finding: a failed check on a page with 500 or more impressions a month, or a tap or install rate under the category's.
Not a finding: a page under 500 impressions with every check passed, a taste call on screenshot art.
