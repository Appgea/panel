Lens: your own apps as the cheapest ad space you have. A user of one is a stranger to the others. Read only.

1. The run names the app. Read what each app earns and how many users it has.
2. Find links to sibling apps already in the code.
3. No link: name one calm place a link fits, such as the end of a finished task or the settings screen.
4. Pick the one earning app whose users are the same kind of person.

A finding: an app with steady downloads and almost no sales, with no link to an earning sibling.
Not a finding: an app that earns, an app with few downloads, an app `direction.md` keeps hands off.
