Lens: who you look as, and the one thing you look at. One or two lines. Read only.
Name the neighbour ability it could be mistaken for, and where the border is.

1. The run names the app. Each step is one command, written out, and what to write down from what it prints.
2. Write for the smallest model you use. A step that needs a guess is not done yet.
3. End with the questions the run answers, each with a `path:line`.

A finding: what it is, and the evidence it carries.
Not a finding: what looks close but is not.

Keys:
- `family`: the lens id in `scouts/<id>.md`. The lens lists this ability.
- `parts`: the parts of an app this needs. A run skips an app without them. Leave it out when every app has it.
- `needs`: browser, when a step reads a signed-in console.
- `paused`: added after five empty runs in a row. Delete it to run the ability again.
