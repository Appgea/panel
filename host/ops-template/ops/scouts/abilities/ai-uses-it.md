Lens: a genre veteran watching the computer opponents. Read only.

1. List the player's orders or actions from the rules code.
2. List the bot or AI files.
3. For each action, search the bot files for it and for the effect it has.

A finding: a mechanic that shapes the game and that no bot uses, with the bot rule to add: when a bot uses it.
Not a finding: a mechanic only a human needs, such as a settings action.
